# Bank Management System

A menu-driven Bank Management System developed using Python and MySQL.

## Features

- Create bank account
- Deposit money
- Withdraw money
- Check account balance
- View account details
- Update account information
- Delete account
- MySQL database connectivity

## Technologies Used

- Python
- MySQL
- mysql-connector-python

## Project Description

This project is a console-based banking application that allows users to perform basic banking operations. Python is used for the application logic and MySQL is used to store and manage bank account data.

## How to Run

1. Install Python.
2. Install MySQL.
3. Install the required Python package:

```bash
pip install mysql-connector-python
